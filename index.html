数据导出

支持导出为 ZIP 包（含图片）或纯 JSON 文件。可选择时间范围筛选，图片会自动打包到 ZIP 中。

数据导入

支持导入 ZIP 包（自动还原当前设备图片）或旧格式 JSON 文件。登录后导入会覆盖当前账号的云端文字数据，照片不会同步到其他设备。

缓存与云端数据

清除本机缓存不会删除 CloudBase 云端数据；删除云端数据只影响当前登录账号，需要强确认。

快速开始

  1. 在「个性设置」里填写名称和座右铭，让页面变成自己的日程打卡。
  2. 在「每日模板」里添加固定任务，选择分类和重复规则。
  3. 回到左侧当天任务列表，点击方框即可完成打卡。

模板与任务

  • 每日重复：每天自动生成任务。
  • 工作日重复：仅周一到周五生成任务。
  • 每周重复：可指定某个星期几生成任务。
  • 新增模板后，如果符合当天规则，会立即出现在今天任务里。

图片功能

  • 在模板中可上传参考图片，在每日任务中可上传打卡照片。
  • 支持点击选择、拖拽上传、粘贴上传三种方式。
  • 图片会自动压缩（最大 1920px，JPEG 质量 0.8）以节省存储空间。
  • 点击缩略图可全屏查看大图，支持左右箭头键切换。
  • 在「个性设置」中可设置图片保留天数，默认 180 天（约 6 个月）。
  • 超过保留时间的图片会在打开页面时自动清除。

AI 智能分析

  • 在「个性设置」中配置 AI 接口（Endpoint、API Key、模型名称），支持 OpenAI 兼容格式。
  • 点击顶部 AI 打卡分析 按钮，可生成三种报告：
    • 生成分析报告：分析近 30 天完成率趋势、薄弱环节和改进建议。
    • 生成本周周报：总结本周表现、亮点和不足、下周改进建议。
    • 今日建议：针对今天的任务给出执行顺序、时间分配、执行技巧和完成率预估。
  • 报告支持 Markdown 格式渲染，流式输出（打字机效果）。
  • 同一天的「今日建议」会自动缓存，重复点击不会重复调用 AI。
  • 可选择 AI 分析风格：友好鼓励、严格督促、简洁高效，或自定义 Prompt。
  • 主页的智能激励语每天自动更新一次，不替换座右铭。

历史回看

  • 通过顶部日期可查看任意一天的任务完成情况。
  • 「历史回看」标签按月显示日历，颜色深浅表示完成率。
  • 点击日历中的某一天可跳转到该日详情。

数据备份与恢复

  • 在「数据管理」标签中可导出和导入数据。
  • 导出：有图片时生成 ZIP 包（含 data.json 和 images 文件夹），无图片时生成 JSON 文件。支持按时间范围筛选。
  • 导入：支持 ZIP 包（自动还原图片到浏览器）和旧格式 JSON 文件。导入会替换当前所有数据。
  • 清除：永久删除所有数据，需二次确认，不可恢复。
  • 建议定期备份数据，尤其是有重要图片记录时。
